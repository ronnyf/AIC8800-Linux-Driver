AIC8800 Install Guide

Fullmac WiFi driver build, firmware, and load procedure for AIC8800-series USB adapters — verified on Ubuntu 24.04, kernel 6.8.0-136-generic.

a69c:8800 · base/DC/DW a69c:8d80 · D80 kernel 6.0 – 7.2

1

Identify your chip

The USB product ID decides which firmware path you're on. Run:

lsusb | grep -i aic

Match the ID against the two chips this driver supports.

firmware included

a69c:8d80 — AIC8800D80

Ships in fw/aic8800D80. No extra download needed.

firmware missing

a69c:8800 — base / DC / DW

Older chip, same PID as the D80's download-mode bootloader. Repo has nothing for it — see step 4.

2

Install kernel headers

Must match the running kernel exactly.

sudo apt install linux-headers-$(uname -r)
3

Build and install the module

On kernel 6.0 – 6.16 (e.g. Ubuntu's stock 6.8), main fails to build — three cfg80211 compat guards assume the ABI change landed at 6.0, but it actually landed at 6.17. Check out PR #27 until it merges. 
git clone https://github.com/ronnyf/AIC8800-Linux-Driver.git
cd AIC8800-Linux-Driver
# add LLVM=1 if your kernel was built with clang
make -C drivers/aic8800
sudo make -C drivers/aic8800 install
4

Firmware — base / DC / DW chips only

Skip this step entirely on D80. Otherwise pull the matching set from armbian/firmware:

sudo mkdir -p /lib/firmware/aic8800
for f in fmacfw.bin fw_patch.bin fw_adid.bin fw_patch_table.bin aic_userconfig.txt; do
  sudo curl -sSL -o /lib/firmware/aic8800/$f \
    https://raw.githubusercontent.com/armbian/firmware/master/aic8800/USB/aic8800/$f
done
5

Load the driver

sudo modprobe aic_load_fw
sudo modprobe aic8800_fdrv
6

Verify

lsmod | grep aic
ip link show | grep wlx        # interface name is wlx<mac>
nmcli device wifi list ifname <interface>
sudo dmesg | tail -30           # check here if the interface never appears
